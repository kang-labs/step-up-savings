# 증액저축 계산기 — 설계 스펙

- 작성일: 2026-10-12
- 상태: 설계 승인됨, 스펙 검토 대기

## 1. 목적

엑셀로 하던 "목표금액 달성용 월 저축액" 계산을 작은 데스크톱 앱(.exe)으로 옮긴다.
목표금액·현재자산·날짜·월급날을 넣으면 두 가지를 바로 보여준다.

1. **균등 저축** — 매달 같은 금액을 저축할 때의 월 저축액
2. **증액 저축** — 매년 월 저축액을 정해진 금액만큼 올릴 때, 연도별 월 저축액

여러 목표(예: 1억, 5천만 원)를 "플랜"으로 나란히 만들어 두고 탭으로 오간다.

### 성공 기준

- `npm run build` 한 번으로 `release/증액저축계산기.exe` 가 새로 만들어진다(기존 파일 덮어쓰기).
- exe 를 더블클릭하면 설치 없이 작은 창이 뜨고, 인터넷 없이 동작한다.
- 엑셀 시트의 2026년 시작 열과 계산값이 1원 이내로 일치한다(차이는 올림 처리 때문).
- 입력한 플랜은 앱을 껐다 켜도 남아 있다.

## 2. 기술 스택

Tauri 는 exe 크기가 작지만 Rust·VS C++ Build Tools 설치가 필요해 제외했다.

## 4. 데이터 모델

```ts
type Plan = {
  id: string;
  name: string;               // 비어 있으면 탭에 "1억 목표"처럼 목표금액으로 자동 표시
  goal: number;               // 목표금액, 기본 100_000_000
  currentDate: string | null; // 'YYYY-MM-DD'. null = 항상 오늘
  endDate: string;            // 기본 '2029-12-31'
  asset: number;              // 현재자산, 기본 0
  payday: number;             // 월급날 1~31, 기본 21
  stepUp: number;             // 연간 증액액, 기본 100_000
};
```

- 저장: `localStorage['step-up-savings/v1'] = { plans: Plan[], activeId: string }`.
  Electron 에서는 사용자 데이터 폴더(`%APPDATA%`)에 남으므로 재실행해도 유지된다.
- 저장된 값이 없거나 깨져 있으면 기본 플랜 1개로 시작한다.
- 현재날짜를 오늘 날짜로 고르거나 "오늘" 버튼을 누르면 `null` 로 저장한다 → 다음 실행 때도 그날의 오늘로 계산된다.

## 5. 계산 규칙 (`lib/savings.ts`)

날짜는 `{y, m, d}` 정수로만 비교한다(시간대 영향 없음).

### 5.1 남은 개월 수

현재날짜의 달부터 완료날짜의 달까지 매달 월급날을 만든다.
월급날이 그 달에 없으면(예: 31일인데 2월) 그 달 말일을 월급날로 본다.

**포함 조건: `현재날짜 < 그 달 월급날 ≤ 완료날짜`**

- 월급날 전날까지 입력 → 이번 달 포함 (+1개월)
- 월급날 당일 이후 입력 → 이미 받은 월급이므로 이번 달 제외
- 완료일이 그 달 월급날보다 이르면 완료월은 제외 — 마지막 월급을 못 받으므로 1개월 적어진다
- 완료일이 월급날 당일이면 그날 월급을 받으므로 완료월 포함

완료월 예시 (현재 2026-10-12, 월급날 21일):

| 완료날짜 | 2029년 8월 월급(8/21) | 남은 개월 수 |
|---|---|---|
| 2029-08-30 | 받음 | 35 (2026: 3, 2027: 12, 2028: 12, 2029: 8) |
| 2029-08-21 | 받음 | 35 |
| 2029-08-20 | 못 받음 | 34 (2029: 7) |

포함된 월급날을 연도별로 묶어 `{year, months}` 목록을 만든다. 남은 개월 수 = 전체 합.
"다음 월급날" = 포함된 첫 월급날.

### 5.2 금액

- 차액 = 목표금액 − 현재자산
- **모든 월 저축액은 1원 단위 올림** — 목표에 반드시 도달하도록.

**① 균등 저축**: `ceil(차액 / 남은 개월 수)`

**② 증액 저축**: 월급날이 있는 첫 연도를 첫해(i = 0)로 하고, i 번째 해의 월 저축액은 `x + i × 증액액`.

```
Σ m_i × (x + i × 증액액) = 차액
x = ceil( (차액 − 증액액 × Σ i·m_i) / Σ m_i )
```

- 첫해 = 현재날짜의 연도. 단, 그 해에 남은 월급날이 없으면(예: 12월 25일, 월급날 21일) 다음 해가 첫해.
- 결과 행: `{ 연도, 개월수, 월 저축액, 연간 합계 }`. 총 저축액(연간 합계의 합)도 함께 반환.

### 5.3 상태

| 조건 | 상태 | 화면 |
|---|---|---|
| 날짜가 비었거나 잘못됨 | `invalid` | "날짜를 확인해주세요" |
| 차액 ≤ 0 | `achieved` | "이미 목표를 달성했어요 🎉" |
| 남은 개월 수 = 0 | `noMonths` | "완료일까지 남은 월급날이 없어요" |
| 증액 저축의 x ≤ 0 | `ok` + `stepUpTooLarge` | 균등 결과는 보여주고, 증액 표 대신 "연간 증액액이 너무 커요" |
| 그 외 | `ok` | 전체 결과 |

### 5.4 엑셀 대조값 (테스트 케이스)

목표 1억, 완료 2029-12-31, 월급날 21일 기준.

| 현재날짜 | 현재자산 | 증액 | 개월 | ① 균등 | ② 첫해 x |
|---|---|---|---|---|---|
| 2026-01-05 | 27,504,909 | 130,000 | 48 (2026~29 각 12) | 1,510,315 | 2026: 1,315,315 → 2027: 1,445,315 → 2028: 1,575,315 → 2029: 1,705,315 |
| 2026-04-21 | 33,652,620 | 130,000 | 44 (2026: 8) | 1,507,895 | 2026: 1,295,168 |
| 2025-11-13 | 26,117,974 | 100,000 | 50 (2025: 2) | 1,477,641 | 2025: 1,237,641 → 2026: 1,337,641 |

추가 경계 케이스: 2026-04-20 → 45개월, 5.1 의 완료월 예시 3건(08-30 → 35, 08-21 → 35, 08-20 → 34),
월급날 31일 → 2월은 말일 포함, 현재 2026-12-25 → 첫해 2027, 자산 ≥ 목표 → `achieved`.

## 6. 화면

창: 460×820, 최소 400×640, 크기 조절 가능, 메뉴바 없음, 제목 "증액저축 계산기".

위에서 아래로:

1. **헤더 + 플랜 탭** — 앱 이름, `[1억 목표] [5천만 목표] [+]`. 탭이 넘치면 가로 스크롤.
   `+` 는 기본값으로 새 플랜을 만들고 그 탭으로 이동.
2. **입력 카드** — 플랜 이름, 목표금액, 현재날짜(오늘이면 "오늘" 배지, 아니면 "오늘로" 버튼),
   완료날짜, 현재자산, 월급날(1~31), 연간 증액액.
   금액 입력은 입력 중 콤마 자동 표시 + 아래에 "약 7,249만 원" 같은 한글 단위 힌트.
3. **요약 바** — 현재자산/목표 진행률 막대(%), 차액, 남은 개월 수, 다음 월급날.
4. **결과 카드**
   - ① 균등 저축: 월 저축액을 큰 숫자로.
   - ② 증액 저축: 연도 / 개월 / 월 저축액 / 연간 합계 표. 첫해 행에 "첫해" 표시.
5. **차트** — 연도별 증액 월 저축액 막대 + 균등 월 저축액 점선 기준선, 막대 위 금액 라벨.
6. **플랜 삭제** — 카드 하단의 삭제 버튼 → 인라인 "정말 삭제할까요? [삭제] [취소]".
   플랜이 1개뿐이면 삭제 버튼을 비활성화.

비주얼: 따뜻한 아이보리 배경, 딥 그린 포인트 색, 흰 카드 + 부드러운 그림자, Pretendard,
숫자는 `font-variant-numeric: tabular-nums` 로 자릿수 정렬. 라이트 테마만.

## 7. Electron

- `electron/main.cjs`: `BrowserWindow` 생성, `Menu.setApplicationMenu(null)`, `dist/index.html` 로드.
- `contextIsolation: true`, `nodeIntegration: false`, preload 없음(Node API 불필요).
- 외부 링크는 앱 안에서 열지 않는다(`setWindowOpenHandler` → deny).
- `package.json` 의 `build` 설정: `productName: 증액저축계산기`, `directories.output: release`,
  `win.target: portable`, `portable.artifactName: 증액저축계산기.exe`, `files: [dist/**, electron/**]`.
  한글 파일명으로 빌드가 실패하면 `StepUpSavings.exe` 로 바꾼다.
