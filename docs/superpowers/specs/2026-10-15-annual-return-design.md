# 연수익(복리) 반영 설계

날짜: 2026-10-15

## 목적

지금 계산은 모은 돈이 불어나지 않는다고 본다. 플랜마다 **연수익 n%** 를 켜면, 현재자산과 매달 넣는 돈이 그 수익률로 불어난다고 보고 균등·증액 월 저축액을 다시 계산한다. 목표는 "완료날짜에 불어난 금액이 목표금액이 되는 것". 세금은 반영하지 않는다.

## 사용자와 정한 것

- 입력: `연수익` 체크박스 + `연 n %` 칸. 숫자와 소수점만, 소수 둘째 자리까지, 0~30%.
- 수익 대상: 현재자산 + 매달 넣는 돈 모두.
- 계산 방식: **적금식** — 1년 안에서는 넣은 뒤 남은 개월만큼 단리, 해가 바뀔 때 합쳐서 복리.
- 결과 표시: 수익 반영 월 저축액 + "넣는 돈 / 예상 수익" 을 나눠 보여 준다.

## 계산 규칙

연 수익률 r (예: 5% → 0.05). 연도별 월급날 수 m_i (지금의 `groupByYear` 결과, i = 0 이 첫해).

- 그해 시작 금액은 `g_i = 1 + r × m_i / 12` 배가 된다 (1년 내내면 r 전체, 10월 시작 첫해 3개월이면 r × 3/12).
- 그해 j 번째(1부터)로 넣은 돈은 `1 + r × (m_i − j) / 12` 배 — 그해 마지막에 넣은 돈은 수익 0. 그해 넣은 1원씩의 연말 가치 합은 `D_i = m_i + r × m_i (m_i − 1) / 24`.
- 연말 금액이 다음 해 시작 금액 (해마다 복리). 마지막 해는 완료날짜에서 끝난다.
- 완료날짜 가치 배수: 현재자산 `G = Π g_i`, 그해 넣은 1원 `F_i = D_i × Π_{k>i} g_k`.
- 필요 금액 `need = 목표금액 − 현재자산 × G`.
  - 균등: `x = 올림(need / Σ F_i)`
  - 증액: `x = 올림((need − 증액액 × Σ i·F_i) / Σ F_i)`, i 번째 해는 `x + i × 증액액` (기존과 같음)
- **r = 0 이면 G = 1, F_i = m_i 로 지금 공식과 똑같다.** 수익률 0 은 "수익 없음" 과 같은 결과.
- 올림은 소수 오차로 1원이 더 올라가지 않게 `ceil(v − 1e-6)`.
- 넣는 돈 = Σ 월액 × 개월. 완료 금액 = 현재자산 × G + Σ 월액_i × F_i. 예상 수익 = 내림(완료 금액 − 현재자산 − 넣는 돈).
- 개월 수는 지금처럼 그해 월급날 수로 센다(근사). 마지막 해에 월급날이 없으면 그 며칠의 수익은 셈하지 않는다.

검증(임시 스크립트, 무작위 입력):
- 100만 원 + 10만 원 × 12개월, 연 5% → 1년 뒤 2,277,500원.
- r = 0 에서 기존 `calcPlan` 과 8,463건 모두 일치.
- 공식의 월액으로 한 달씩 넣어 보면 11,653건 모두 목표 도달, 1원 적게 넣으면 모두 미달(최소 금액).
- 은행식 매달 복리보다 월액이 조금 크다(1억 예시 연 5%: +0.34%, 연 10%: +1.57%). 항상 "조금 더 넣으라" 쪽이라 목표에 못 미치지 않는다.

## 결과 상태

기존 `invalid / achieved / noMonths / ok` 에 하나 추가:

- `grown`: 현재자산만 불려도 완료날짜에 목표 이상 (`need ≤ 0`). 남은 개월·다음 월급날과 완료 금액(내림)을 함께 돌려준다. 수익률이 0 이면 생기지 않는다(`achieved` 가 먼저 걸림).

`ok` 결과에 `flatProfit`(균등 예상 수익), `stepUp.profit`(증액 예상 수익)을 더한다. `stepUp.total` 은 지금처럼 넣는 돈 합계.

## 저장

- `Plan` 에 `returnOn: boolean`(기본 false), `returnBp: number`(수익률 × 100 정수, 3.25% → 325, 0~3000, 기본 0) 추가. 정수로 저장해 소수 오차를 없앤다.
- 저장 키 `step-up-savings/v1` 은 그대로. 예전 데이터에 두 값이 없으면 기본값으로 채워 읽는다 — 휴대폰을 업데이트해도 플랜이 사라지지 않는다. 값이 있는데 타입·범위가 틀리면 그 플랜은 버린다(기존 규칙과 같음).
- 계산에는 `returnOn ? returnBp : 0` 을 넘긴다. 체크를 꺼도 수익률은 남아 다시 켜면 돌아온다.

## 입력 화면

`PlanForm` 의 연간 증액액 다음 칸(2열이면 왼쪽 아래):

- 칸 머리에 `☐ 연수익` 체크박스.
- 입력칸 `연 [   ] %` — 꺼져 있으면 비활성(흐리게). 처음 켜면 비어 있고, 비어 있거나 0 이면 수익 없음과 같다.
- 입력 거르기(순수 함수): 숫자·소수점 외 글자는 지우고 소수점은 하나만, 소수 셋째 자리 이상이나 30 초과가 되는 입력은 받아들이지 않는다(이전 값 유지). 입력 중인 `3.` 같은 글자를 지키려고 입력칸은 자기 글자 상태를 갖고, 바뀔 때마다 `returnBp` 로 바꿔 저장한다.
- 켜져 있을 때 칸 아래 안내: `적금식 · 해마다 복리 · 세금 제외`.
- 새 색은 쓰지 않는다. 체크박스는 `accent-color: var(--accent)`, 비활성은 투명도만.

## 결과 화면

수익이 실제로 반영될 때(켜짐 + 수익률 > 0)만 바뀐다.

- 두 결과 카드 제목 줄 끝에 `연 5% 수익` 배지(기존 `.badge`).
- 균등 카드 아래 줄: `39개월 동안 매달 · 넣는 돈 59,942,922원 · 예상 수익 10,057,095원` (꺼져 있으면 지금처럼 `· 총 …원`).
- 증액 표 맨 아래: `총 저축액` 대신 `넣는 돈 합계`, `예상 수익` 두 줄.
- 차트 점선(균등 금액)은 수익 반영 금액으로 자동 반영.
- `grown` 안내: 📈 `지금 자산만 굴려도 목표에 닿아요` / `연 5% 수익이면 완료날짜에 약 1억 300만 원이 돼요.`
- 요약(진행률·차액·남은 개월·다음 월급날)은 그대로. `grown` 에서도 남은 개월과 다음 월급날을 보여 준다.
